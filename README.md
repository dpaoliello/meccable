# Meccanoid Bluetooth tools

These have only been tested with a Meccanoid G15KS.

## meccable - A Rust Bluetooth library and tools for Meccanoid

A Cargo workspace containing a Rust library for controlling Meccanoid robots via Bluetooth, along
with CLI tools that use it.

It should also work with the Meccanoid G15 - but that device is missing the elbow and neck servos.

Originally forked from <https://github.com/iamsrp/pymecca>.

## meccamote - Control meccanoid with a Wiimote

A CLI that controls a Meccanoid robot using a Wiimote and its nunchuck.
