# meccable - A Rust Bluetooth library and tool for Meccanoid

This is a simple Rust library for controlling Meccanoid via Bluetooth, along with a CLI tool for
using that library.

This has only been tested with a Meccanoid G15KS.

It should also work with the Meccanoid G15 - but that device is missing the elbow and neck servos.

Originally forked from <https://github.com/iamsrp/pymecca>.
